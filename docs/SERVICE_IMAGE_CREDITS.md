# Service inspiration image credits

These Commons photographs are **illustrative category references only**. They are not associated with, endorsed by, or representative of any Salon Management System professional. They are never substituted for a professional-uploaded portfolio image when one exists. Service cards label them “Illustrative reference · not this professional’s portfolio.” The fallback is keyword-matched only for braids/cornrows, makeup, nails, and hair treatment. No suitable wig-installation photo was verified for this patch; professionals should upload their own permitted example.

The UI uses Wikimedia Commons thumbnails at 640px with lazy loading rather than full-size originals. They remain remotely hosted; a failed network load leaves the neutral local placeholder. They are not service-worker cached in Phase One because they are cross-origin.
